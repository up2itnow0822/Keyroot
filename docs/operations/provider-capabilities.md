# Capability and admission coverage

A documented protocol, fixture or trusted verifier callback is not evidence of Bill's account entitlement. Actual account, configuration, scope, store authority and consumer evidence must be gathered through their owning workflows before live admission. Unknown or unsupported actions remain guided or inventory-only.

| Surface | Current bounded evidence | Remaining proof |
| --- | --- | --- |
| Versioned store reference | OpenBao KV v2 adapter and disposable official-image integration exercise CAS and scoped reads. | Establish the pilot store's actual authority, backup and shared epoch. OpenBao is a reference, not an admitted installation. |
| 1Password candidate | [Documented integration assessment](onepassword.md); no account or secret operations performed. | Its hosted model differs from R2, and documented CLI writes do not establish the required remote CAS/fencing contract. Decide pilot scope before building or admitting a write adapter. |
| OpenAI service-account issuer | Fixed scoped protocol and synthetic issuer transports exercise create, store, reconciliation and revoke classification. | Confirm the specific project/account entitlement, permissions, safe probe and actual outcomes. |
| GitHub Actions and Vercel delivery | Fixed-origin transports and synthetic responses exercise mapped delivery. | Confirm actual destination/account authority and separate named-run adoption; a push is not use. |
| Local env and wrapper | Signed fixture file updates, rollback and managed process groups are exercised. | Verify each actual machine, mapping, custody and outage behavior; unmanaged copies remain outside control. |
| Other issuers and dashboards | Guided recipes, trace proposals, admission checks and a synthetic mediation broker exist. | Provider-specific account rehearsal, browser/OS isolation and secret-safe observation evidence remain open. Broad admin sessions retain their account blast radius. |
| OAuth and native subscriptions | Typed local-family and native-session tests retain unknown outcomes. | Production refresh remains with the issuer/native client. Verify platform-specific storage, sign-out and session telemetry before making claims. |

The API-first, admitted-dashboard, then guided path is a capability decision per account and consumer, not a blanket provider guarantee. Never represent unavailable checks or undetected copies as clean coverage.
