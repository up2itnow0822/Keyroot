# Guided Procedures and Recipes

## Purpose
- Provide resumable human guidance and a bounded path from trace proposals to admitted recipes.

## Ownership
- This domain owns recipe schema, draft progress, trace sanitization and admission policy. The controller worker owns mediation.

## Local Contracts
- Traces are proposals, never executable page/model text. Recipe hash/account/destination changes invalidate progress and admission.
- Guided completion is signed owner attestation, with provider/store outcomes separately unverified.
- Admission permits a recipe version; every execution effect still consumes distinct finite signed run authority.
- Synthetic broker proof is process-local protocol evidence. Live OS/browser isolation, actual account rehearsal and applicable hosted-model disclosure remain separate pending gates.

## Work Guidance
- Preserve checkpoint pauses and withhold all observations outside the fixed metadata channel.

## Verification
- Recipe tests in `npm test`; worker adversarial fixture in `npm run test:integration`.
